# feel-food-web

Tienda online de **Feel Foods**, mixes y frutos secos de Chajarí, Entre Ríos. Se arma el pedido y se manda por WhatsApp.

- Web estática: HTML, CSS y JavaScript, sin servidor ni base de datos.
- Para verla: abrir `index.html` en el navegador.
- Precios, productos, WhatsApp, pedido mínimo y textos: se editan en `productos.js`.
- Fotos de productos: van en `img/`, en WebP de unos 900 px.
- Contexto completo y pendientes: `CONTEXTO-TIENDA.md`.
